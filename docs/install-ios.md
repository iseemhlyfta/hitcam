# Установка HitCam на iPhone без Mac

Приложение не публикуется в App Store. Его собирает GitHub Actions, а на телефон его ставит
[Sideloadly](https://sideloadly.io/) с Windows, подписывая сборку вашим Apple ID.

1. Установите на ПК **iTunes** или **Apple Devices** из Microsoft Store: нужны драйверы iPhone.
2. Скачайте `HitCam-ios-unsigned.ipa` со страницы *Releases* (или `HitCam-unsigned.ipa` из артефактов последнего
   успешного запуска workflow **iOS**, вкладка *Actions* репозитория).
3. Подключите iPhone кабелем, запустите Sideloadly, перетащите IPA, введите Apple ID и нажмите *Start*.
   Для входа лучше завести отдельный Apple ID: Sideloadly передаёт учётные данные только серверам Apple.
4. На iPhone: *Настройки → Основные → VPN и управление устройством* → доверьте свой Apple ID.
5. Включите *Настройки → Конфиденциальность и безопасность → Режим разработчика* (iOS 16+) и перезагрузите телефон.
6. При первом запуске разрешите **Камеру** и **Локальную сеть**.

## Ограничения бесплатного Apple ID

- Подпись действует **7 дней**. Потом приложение перестаёт запускаться, и его нужно переустановить через Sideloadly
  (настройки и сопряжение сохраняются). Sideloadly умеет автоматически обновлять подпись, если ПК и iPhone в одной сети.
- Не больше 3 приложений, установленных таким способом, одновременно.
- Платный Apple Developer ($99/год) продлевает подпись до года и открывает TestFlight.
