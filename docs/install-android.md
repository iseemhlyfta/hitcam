# Установка HitCam на Android

Приложение не публикуется в Google Play. Его собирает GitHub Actions, а на телефон оно ставится из файла APK.
Нужен Android 8.0 или новее.

1. Откройте на телефоне страницу *Releases* репозитория и скачайте `HitCam-android.apk`
   (браузер может спросить, точно ли сохранить файл, — подтвердите).
2. Откройте скачанный файл из уведомления браузера или из «Загрузок».
3. Если установка из этого источника запрещена, телефон предложит открыть настройки: включите
   **«Разрешить установку из этого источника»** и вернитесь назад. То же вручную:
   *Настройки → Приложения → Специальный доступ → Установка неизвестных приложений* → ваш браузер или
   файловый менеджер → **Разрешить**. Названия пунктов немного отличаются у разных производителей.
4. Нажмите **«Установить»**.

## Xiaomi, Redmi, POCO (HyperOS, MIUI)

- При первой установке из браузера появится запрос о неизвестных источниках — разрешите его, как в шаге 3.
- MIUI может показать предупреждение с таймером на 10 секунд: дождитесь его, отметьте, что понимаете риски,
  и продолжите.
- Встроенная «Безопасность» проверяет APK перед установкой и может предупредить о приложении не из магазина.
  Если включена **«Защита»** (режим, блокирующий приложения не из магазина), разрешите установку в появившемся окне
  или временно отключите её в настройках безопасности.
- «Оптимизация MIUI» и режим разработчика **не нужны**.

## Google Play Защита

Play Защита может сказать, что приложение ей незнакомо. Нажмите **«Подробнее» → «Всё равно установить»**
(в некоторых версиях — **«Установить без проверки»**). Отправлять приложение на проверку не обязательно.

## Первый запуск

1. Разрешите HitCam доступ к **камере**.
2. Телефон и ПК должны быть в одной сети Wi-Fi. Отсканируйте QR-код из HitCam на ПК или введите IP-адрес вручную.
3. При первом подключении введите на телефоне 6-значный PIN с экрана ПК. Дальше телефон подключается без PIN.
4. Во время трансляции держите HitCam **открытым на экране**: Android выключает камеру у свёрнутых приложений.
   Не сворачивайте приложение и не блокируйте экран, пока идёт трансляция.

## Обновление

Скачайте новый `HitCam-android.apk` и установите его **поверх** старого, не удаляя приложение.
Все версии со страницы *Releases* подписаны одним ключом, поэтому настройки и сопряжение с ПК сохраняются.
Если Android отказывается обновлять («Приложение не установлено» из-за конфликта подписи), значит, установлена
сборка с другой подписью (например, из артефактов pull request): удалите её и поставьте версию из *Releases* —
сопряжение придётся пройти заново.
